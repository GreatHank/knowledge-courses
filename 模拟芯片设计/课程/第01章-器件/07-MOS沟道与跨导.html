MOS 的沟道、夹断与平方律

为什么提高栅压能增加电流，而提高漏压却逐渐失去控制力？

← 返回本章目录原书 PDF 29～33

先认出四个端子

MOS 用绝缘栅的电场改变表面载流子。早期器件受到界面与可移动电荷影响，阈值难以稳定；书内 1-23～1-24 的历史说明，表面与氧化层控制是形成可靠 MOS 的前提。

在所画的 N 阱结构中，NMOS 的体端（body）通常是公共 P 衬底，PMOS 的体端是 N 阱。将 P 衬底置于最低电位、N 阱置于最高电位，可在相应源漏电压范围内避免结正偏。栅极直流电流很小，但栅电容在交流或切换时仍需充放电。

本图的基本平面结构近似源漏对称。接入电路后，要结合电位、体结偏置和实际器件结构判断源漏角色，不能把“源漏相同”扩展到所有功率或特殊工艺器件。

形成反型沟道，再看漏端变化

对增强型 NMOS，正栅压先排斥空穴，再吸引电子形成反型层。源漏间出现可导电沟道。VDS 很小时，沟道沿途条件接近，电流近似随漏压增加。

沿沟道向漏端走，局部沟道电位升高，栅极相对该处的有效电压减小；漏端反型电荷随之减少。长沟道模型在 VDS≈VGS−VT 附近达到夹断（pinch-off）。夹断并不是切断电流，注入的载流子仍穿过高场区进入漏极。

MOS 的“饱和区”是模拟放大常用区域；BJT 的“饱和”则对应两个结正偏。两者同名，工作含义不同。原书 1-26 把电流—电压曲线斜率称作电阻；准确地说，图上 dI/dV 是微分电导，其倒数才是微分电阻。

平方的是过驱动电压

Vov = VGS−VT；ID = K(W/L)Vov²

沿用原书系数约定，把它记为 K，避免和玻尔兹曼常数及小信号跨导混淆。这个简化平方律适用于长沟道、强反型、饱和区，并忽略沟道长度调制等影响。K 是工艺系数，单位 A/V²；它不是工作点跨导 gm。

gm = ∂ID/∂VGS = 2K(W/L)Vov = 2ID/Vov

在其他端电压固定、阈值不变的条件下求局部导数，才得到跨导（transconductance），单位 A/V。Vov 加倍，理想电流变为四倍，gm 变为两倍；VGS 加倍通常不满足这一关系。原书 1-26 的“电流除以栅压”和 1-34 的“跨导随过驱动平方变化”不能作为定义。

模型条件与跨导定义核对 MIT 6.012，Lecture 10，第 1～4 页。

只改变过驱动电压

解析计算示例：K·W/L = 100 μA/V²，VT = 0.5 V，VDS = 1.5 V；假定长沟道饱和模型成立。

Vov = 0.4 V；VGS = 0.9 V；ID = 16 μA；gm = 80 μS。

体效应让阈值也成为变量

体端电位改变会影响形成反型层所需的栅压，即体效应（body effect）。例如 PMOS 的源极低于公共 N 阱电位时，体源反偏增大，会改变阈值与驱动能力；不能继续沿用体源短接时的同一条曲线。

把 PMOS 放进独立 N 阱并适当连接体端可改善某些偏置情形，但会增加面积且仍须保证结偏置正确。原书“约降低 30%”是示例估计，设计时需要工艺模型。

依据：Hans Camenzind，Designing Analog Chips，February 2005，书内 1-23～1-27。中文为伴读解释；数值与模型条件见正文。
