BJT 如何分配尾电流

两个输入相差一点电压，为什么两路电流一增一减？

← 返回本章目录原书 PDF 67～68

两只管，共用一股电流

差分对（differential pair）用两个输入的电压差控制两路电流。集成电路中的相邻器件往往能做得很接近，即使每只管的绝对参数不够准确，配对后的比较关系仍可能较准。原书从这个特点引出差分对；它并不意味着每一种放大任务都必须采用差分输入，噪声等要求仍可能使单管方案更合适。

把 I1 叫作尾电流（tail current）IT。两管匹配、输入相等且都处于正向放大区时，两个发射极各分到 50 μA。忽略基极电流后，集电极电流也各为 50 μA。V1 升高时，Q1 分到更多电流；尾电流保持不变，Q2 就只能少取一些。

本章约定差分输入 vd = V1−V2。两输入一起移动而差值不变，是共模（common-mode）变化。实际共模电压必须保证输入管和尾电流源都有足够余量；“只看电压差”不代表输入可以任意升降。

完整曲线是弯的，只有中心附近近似直线

以下为伴读推导：两管匹配、温度相同、正向放大，忽略基极电流、Early 效应及失配，尾电流恒定。两管指数关系的比值，加上总电流约束，给出：

IC1/IC2 = exp(vd/VT)，VT = kT/q
IC1 = IT / [1 + exp(−vd/VT)]
IC2 = IT − IC1
ΔI = IC1 − IC2 = IT tanh[vd/(2VT)]

取 VT = 26 mV、IT = 100 μA，vd = 50 mV 时，电流约为 87.25 μA 与 12.75 μA，差值约 74.50 μA。若把中心处的直线外推到这里，会得到约 96.15 μA 的差值，已经明显偏离。

改变差分电压，观察电流分配

解析计算：固定尾电流 100 μA、热电压 26 mV。没有调用器件模型或 SPICE。

v_d = 0 mV；Q1 = 50.00 μA；Q2 = 50.00 μA；差值 = 0.00 μA

单管跨导与差分斜率不要混用

跨导（transconductance）描述电压变化引起的电流变化。原书从动态发射极电阻（dynamic emitter resistance）re 解释这个斜率。它是工作点附近电压增量与电流增量之比，不是一只真实串联电阻。室温取 VT≈26 mV，IE 为 1 mA、100 μA、50 μA 时，re 分别约 26 Ω、260 Ω、520 Ω。

re = VT/IE
单管本征跨导 gm = IC/VT = α/re，α = β/(β+1)
平衡点：∂IC1/∂vd = IT/(4VT)
∂ΔI/∂vd = IT/(2VT) ≈ gm

这里最后的 gm 是每只管在约 IT/2 下的跨导。一侧电流对差分输入的斜率只有它的一半，两侧电流之差的斜率才等于它。后面算单端与差分电压增益时，这个二倍关系不能漏掉。

原书另计发射极接触等欧姆电阻 Re，近似写成 gm = 1/(re+Re)。这对应 α≈1、外部发射极电位固定等条件；保留有限 α 时约为 α/(re+Re)。不要把这项内部串联电阻与第 04 课主动加入的退化电阻混在一起。

温度、基极电流与失配留下的差别

固定 IE 时，re 随绝对温度 T 增大，跨导减小。若尾电流本身随温度变化，就必须把这项变化一起带入，不能只按 re∝T 判断。

有限 β 时，两个集电极电流之和约为 αIT；例如 β=100、尾电流100 μA，和约为 99.01 μA。集电极电压不相等又会通过 Early 效应改变分配。失配则使两路恰好相等所需的输入差值偏离零；这个偏离用输入失调电压（input offset voltage）描述。原书曲线中的非理想性不能全部归为同一种误差。
