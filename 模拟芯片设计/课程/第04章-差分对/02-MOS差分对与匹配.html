MOS 差分对与匹配

没有基极电流之后，跨导与失调还受什么限制？

← 返回本章目录原书 PDF 69～73

换成 MOS，仍在分配尾电流

两只匹配 NMOS 的栅极作为输入，共用源极与尾电流。输入相等且工作区允许时，各分到约 10 μA；V1 增大，M1 多取电流，M2 少取电流。栅极静态电流很小，因此没有 BJT 基极电流那样的固定分流项；漏电与动态充放电电流仍然存在。

本图体端接地，源极却会随输入改变，体效应可能参与工作点变化。检查共模范围时，既要保证尾电流源工作，也要保证两只输入管所需的栅源电压与漏源余量，不能只看栅极有没有取电流。

增加宽度是否增加跨导，要先说固定什么

长沟道、强反型、饱和区近似：
ID = ½βnVOV²，βn = μCoxW/L
gm = βnVOV = 2ID/VOV = √(2βnID)

固定过驱动 VOV 和 L，增大 W，电流与跨导都增加；固定 ID 和 L，跨导只按 √W 增加，所需过驱动减小。图中的尾电流固定，不能把“跨导正比于宽度”不加条件地套进来。

以上平方律用于说明变量关系，不是对图中 0.35 μm 器件的精确拟合。实际要采用对应工艺模型。匹配且对称偏置附近，一侧漏电流对差分输入的斜率仍约为单管 gm/2。

原书由此提醒 MOS 跨导也随温度变化。比较时要说明固定的是电流还是栅压；迁移率与阈值的作用可能相互竞争，不能从这张曲线推出任意偏置下电流都随温度降低。

更大面积有助于随机匹配，也会增加电容

原书在比较相同尺寸的 MOS 与 BJT 时，按其工艺经验给出约 2∶1 的失调差别。这个比例不能当作跨工艺、跨尺寸的通则。MOS 的阈值、电流因子和几何差异都会影响匹配；把全部失调归因于氧化层厚度也过于简单。

增大面积通常有助于降低局部随机失配，但不能自动消除温度梯度、布局不对称或不同偏置造成的误差。W/L 决定电流关系，面积 WL 影响匹配与电容，两者不是同一个量。例如 W、L 同时加倍，W/L 不变，面积却变为四倍。

后面的有源负载与第二级也会把自己的不平衡折算到输入端。选好了输入对，并不等于整个放大器的输入失调已经确定。

依据：Hans Camenzind，Designing Analog Chips，February 2005，书内 4-3～4-7。中文为伴读解释，补充条件与原文差异见正文。
