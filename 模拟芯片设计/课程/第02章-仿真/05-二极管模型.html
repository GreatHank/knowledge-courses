从二极管方程读懂模型

三个参数能描述什么，又漏掉了什么？

← 返回本章目录原书 PDF 48～50

从最小模型开始

.MODEL Diode1 D IS=1E-17 RS=20 CJO=0.85E-12

这是原书模型声明，尚不是完整仿真电路。Diode1 是模型名，D 表示二极管；IS 的单位为 A，RS 为 Ω，CJO 为 F。实例还要指定连接节点并引用这个模型。省略的参数一般采用模拟器默认值，不代表物理效应已被准确测定。

ID = IS[exp(VD / NVT) − 1]，　VT = kT/q
V端子 = VD + IDRS

这是含发射系数 N 的基本结方程，不是完整 SPICE 方程。原书先写省略 −1 的强正向近似，再加入温度和漏电修正；这里明确保留基本式的适用边界。在大电流处，串联电阻压降可能成为主要部分。

按行为读参数，先不用背长公式

要描述的行为本章出现的参数阅读重点
正向电流及温度IS、N、EG、XTI拟合的标称温度与实际结温要区分
额外漏电ISR、NR并非所有 SPICE 方言都同名支持
击穿BV、IBV、TBV1、TBV2击穿电压有指定电流与温度条件
串联压降RS、TRS1、TRS2电流和温度改变端子电压
结电容CJO、VJ、M、FCCJO 是零偏值，不能用在所有偏置
低频噪声KF、AF噪声参数不能由 DC 曲线自动确定

原书还列出用于改变高电流形状的 IKF。所有这些字段都要和所用模型、软件版本核对。2-9 的展开式涉及特定实现及温度定义，不能把印刷长式直接当作各类 SPICE 的统一公式。

结电容随电压变

VD ≤ FC·VJ：
C = CJO·(1 − VD/VJ)−M

VD > FC·VJ：
C = CJO·(1 − FC)−(1+M)·[1 − FC(1+M) + M·VD/VJ]

这是原书 2-10 的分段耗尽电容式。第一段随反向偏压增大而减小；正向电压靠近 VJ 时，不能继续让同一个幂函数发散，模型在 FC·VJ 处接入延伸段。这个接点用于衔接两段模型公式，不代表材料结构在此突变。

例如只取原书 CJO=0.85 pF、VJ=1 V、M=0.5、FC=0.5，则在 −1 V 时 C≈0.601 pF，在 0 V 时为 0.85 pF，在 0.5 V 接点为 1.202 pF。这是公式计算。它只覆盖这项耗尽电容，不等同于完整正向储存电荷模型。

RS 产生热噪声，结电流产生散粒噪声，还可以有低频闪烁噪声。原书 KF·IAF/f 形式表示电流噪声功率谱密度项，不能当成瞬时噪声电流；换成幅度谱密度还要开方。

依据：Hans Camenzind，Designing Analog Chips，February 2005，书内 2-8～2-10。中文为伴读解释，补充条件与原文差异见正文。
