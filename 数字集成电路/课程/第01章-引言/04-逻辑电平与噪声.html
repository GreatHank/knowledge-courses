真实电压怎样承载可靠的 0 和 1

电压受到扰动后，下一级凭什么还能认出正确的逻辑？

0 和 1 是逻辑解释，节点本身仍是连续电压

理想反相器写成 y = ¬x；真实反相器接收的是输入电压 Vin，产生输出电压 Vout。制造偏差、供电扰动和耦合噪声都会改变这些电压，所以不能要求每一个“1”都精确等于某一个数值。

可靠的数字门需要给 0 和 1 留出电压范围，并在逐级传递时恢复有效电平。真值表负责功能，电气特性决定这个功能在什么条件下成立。

图 1.12：先读坐标，再读四个边界

右图横轴是输入电压、纵轴是输出电压；这条 VTC（voltage-transfer characteristic，电压传输特性）描述静态输入输出关系，横轴不是时间。它回答“输入稳定在这里，输出最终落在哪里”。

符号本节怎样使用
VOL、VOH门输出的低、高电平
VIL仍能作为有效低输入的上边界
VIH能作为有效高输入的下边界
VMVTC 与 Vout = Vin 相交的开关阈值

对这里的反相器 VTC，VIL 和 VIH 由斜率 dVout/dVin = −1 的两点界定。它们之间是未定义输入区：电压当然可能经过那里，但不能将停留在那里的电压当作可靠的静态 0 或 1。VM 是整个门的开关阈值，不是单个 MOS 晶体管的阈值电压。

噪声容限量的是“输出到下一层输入边界”的余量

NML = VIL − VOL
NMH = VOH − VIH

低电平受到向上的扰动时，要在跨过下一级 VIL 之前留出余量；高电平受到向下的扰动时，要在跌破 VIH 之前留出余量。比较不同门连接时，应使用驱动门的输出保证值和接收门的输入要求。

教材例 1.5 给出一个旧式 NMOS 门：VOH = 3.5 V、VOL = 0.45 V、VIH = 2.35 V、VIL = 0.66 V。于是 NMH = 1.15 V，NML = 0.21 V。它的低电平余量明显更小；不能只报一个“噪声容限”就认为两侧同样可靠。

数据来自 PDF 23／书内 31 的例 1.5，用于读懂参数，不是 CMOS 或现代芯片的通用电压规格。

还要恢复电平，并减少噪声耦入

如果每一级都把输入偏差原样带到输出，又叠加新的噪声，偏差可能不断累积。再生特性（regeneration）使有效高、低电平附近的小偏差逐级减小，输出重新接近标称电平。教材用反相器链说明这一点：有效电平区的增益绝对值小于 1，过渡区需要足够大的增益来分离两种逻辑状态。

这不表示处于未定义区的任意输入都能被可靠“修复”。逻辑状态已经无法判定时，单靠后续门不能保证恢复原本想传的那个位。

噪声容限（noise margin）与抗噪能力（noise immunity）也要分开。后者还取决于噪声有多少耦合到信号节点。减小耦合可以让摆幅不大的电路仍然可靠；一味增大摆幅，对那些随摆幅一起增大的噪声未必有效。这正是总图“04 → 06”的取舍背景。

扇入、扇出和单向性都在模型边界内

扇入（fan-in）是一个门的输入数；扇出（fan-out）是它驱动的负载门数。后者增加，负载也会改变，可能影响电平和速度。不能因为某个门具有正确真值表，就认为它可以驱动任意多的接收门。

单向性（directivity）要求输出变化尽量不反过来扰动保持不变的输入。真实电路有输入输出间的电容耦合，只能控制这种影响。教材的理想门用无限输入阻抗、零输出阻抗和陡峭且对称的 VTC 作为比较尺度；实际门需要在负载、供电和噪声条件下检查。

下一课把同一节点从“最终电压对不对”转到“多久才到达”：扇出和连线负载会再次出现。
