把线切得更细，看到延迟怎样分布

令线均匀、总长度为 L，单位长度参数为 r、c，总量 R = rL、C = cL。用 N 段 RC 链近似，每段电阻 R/N、电容 C/N，电容放在各段末端。对理想阶跃源、无额外末端负载，上一课的公式给出：

τE,N = Σk=1…N (C/N)(kR/N)
= RC(N+1)/(2N) → RC/2 = rcL²/2

全部电容集中在总电阻之后，相当于 N = 1，得到 RC。分布线的部分电容靠近源端，不需要经过全部线电阻，所以时间矩更小。若 r、c 不变，长度加倍使 R 和 C 都加倍，线自身延迟尺度增加四倍。

L² 结论对应当前均匀无缓冲 RC 线模型；它没有包含任意驱动器、接收负载、分支或插入缓冲器后的变化。

图 4.15：远端的波形逐渐变缓

固定一个时刻比较不同位置：近源节点先升高，远端节点仍较低。再固定 x = L，看它随时间逐渐充电。沿线电压并非一起跳变，因此不能再把整条线视为一个电容节点。

每小段的流入电流减去流出电流，等于本段电容充电电流。令分段长度趋于零，得到教材的扩散方程：

rc · ∂V/∂t = ∂²V/∂x²

这里“扩散”描述 RC 网络电压随时间和位置的变化，不是说电子必须走完整根线后远端才有反应。图是教材仿真结果，本页面没有重新执行该仿真。

0.5RC 与 0.38RC 是不同量

对教材所比较的均匀分布线、理想阶跃驱动且末端无额外负载，表 4.7 给出以下近似：

比较量单个集中 RC均匀分布 RC 线
50% 到达时间0.69RC0.38RC
10%→90% 上升时间2.2RC0.9RC
零到 90% 时间2.3RC约 1.0RC
Elmore 时间矩RC0.5RC

0.5RC 是上一节推得的时间矩。若强行用单指数替代分布响应，再乘 ln(2)，会得 0.347RC，与表中的 0.38RC 不同，因为分布网络不是单极点。表中约 63% 的特征时间也写为 0.5RC，但不能据此把任意网络的时间矩定义为 63% 时间。

例 4.8 的 Al1 线有 R = 7.5 kΩ、C = 11 pF，RC = 82.5 ns，所以 0.38RC ≈ 31.35 ns。相同长度与宽度换成例中的多晶硅约 111.7 μs，Al5 约 4.16 ns；比较的是原书参数下的线自身响应。

图 4.16：驱动和连线都有贡献

源电阻 Rs 为全部线电容充电；线内电阻按位置影响下游电容。例 4.9 得到：

τE = RsCw + RwCw/2
t50% ≈ 0.69RsCw + 0.38RwCw

第二行是教材的延迟近似，不是把第一行整体乘同一常数。比较第一行两项，线内项达到驱动项时，L ≥ 2Rs/r。取 Rs = 1 kΩ、r = 0.075 Ω/μm，得约 2.67 cm。

这仍是量级判据。判断能否省略线电阻，还要比较输入边沿时间与 RC：缓慢输入使沿线更接近等电位，快速输入使分布效应更明显。不存在只凭“几毫米”就适用于所有工艺和驱动器的固定界限。
