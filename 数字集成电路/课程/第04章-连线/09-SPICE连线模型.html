分布参数必须连同长度与参考节点输入

教材 SPICE3 的 URC（uniform distributed RC）模型在内部生成分段网络。它需要两端节点、电容参考节点、线长，以及单位长度电阻和电容；可另指定分段数。例 4.14 原稿为：

U1 N1=1 N2=2 N3=0 URCMOD L=50m N=6
.MODEL URCMOD URC(RPERL=75K CPERL=100pF)

N1、N2 是线两端，N3 是电容接到的参考节点，此例为地。RPERL 和 CPERL 分别以 Ω/m、F/m 为基本单位。按教材的 SPICE 尺度后缀，50m 是 0.05 m，75K 是 75000 Ω/m，100pF 表示 100 × 10−12 F/m。因此总 R = 3750 Ω、总 C = 5 pF；50m 不是 50 米，100pF 是单位长度参数，不能直接当成整线总电容。

这里保留原稿实例写法并解释含义，不保证这行带 N1= 等标记的写法可直接用于任意仿真器。未提供或执行完整网表；具体实例语法、后缀与模型支持应按所用软件核对。

图 4.26：先守住总量，再比较空间分布

上排 π 模型在串联 R 两端各放 C/2；T 模型在中间电容 C 两侧各放 R/2。两者总量相同，但电容相对端点的位置不同，不能假定所有频率与所有终端下响应相同。

看左下 π₃：三个电阻各 R/3，两个端点各 C/6，内部节点各 C/3。电阻总和仍是 R，电容总和 C/6+C/3+C/3+C/6 = C。右下 T₃ 的端部电阻各 R/6、内部两个各 R/3，三个电容各 C/3，也保持总量。

这些网络把章节图的 05–06 → 09“RC 梯形网络离散” 变成具体连接。分段增加通常能更细地表示沿线变化，但也增加求解量。书中称 π₃ 误差小于 3%，未在该处完整说明误差指标、激励和终端范围；本课不把这个数字当作所有仿真的精度保证。

传输线输入的是阻抗与飞行时间

无损传输线模型用 Z₀ 描述行波的电压电流比，用 TD 描述整线飞行时间。也可用频率 F 与归一化电气长度 NL 表示同一延迟：

NL = F · TD

NL 表示相对于频率 F 对应波长的长度比例，是无量纲数。例如 TD = 1 ns、F = 100 MHz，则 NL = 0.1；这不是把线长写成 0.1 m。

教材介绍把长线分成短段并加入串联电阻来近似损耗，同时提醒精度与时间步长的代价。模型分得更细不自动更可靠：参数、激励、终端、回流路径及所需观测量都必须一致。

原书关于“没有有损传输线模型”的说法属于它当时讨论的软件背景，本课不据此描述当前 SPICE 产品。例 4.13 的仿真占位也没有补成虚构结果。
