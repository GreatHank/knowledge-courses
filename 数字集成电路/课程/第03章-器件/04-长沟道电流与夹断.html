漏端电位升高，靠近漏端的沟道电荷减少

先固定体偏置与阈值，考虑 VGS > VT 的 NMOS。图中源端电位为零，沿沟道向漏端走，局部电位 V(x) 从 0 升到 VDS。栅相对该处沟道的电压为 VGS − V(x)，越靠近漏端，控制电压越小。

令过驱动电压 VGT = VGS − VT。在渐变沟道、强反型近似下，单位面积反型电荷为：

Qi(x) = −Cox[VGT − V(x)]，　Cox = εox/tox

Cox 的单位是 F/m²，表示单位面积氧化层电容，不是整个栅的电容。负号对应电子电荷；电流公式里要同时考虑电子的运动方向。

把整条沟道串起来，得到电阻区电流

在低横向电场近似下，载流子速度与电场成正比。宽度 W 决定可并行输送的电荷量，长度 L 决定电位变化经过的距离。沿 x 积分后，电流由从源到漏的电荷分布共同决定：

β = μnCoxW/L = k′nW/L
ID = β[VGTVDS − VDS²/2]，　0 ≤ VDS ≤ VGT

式中的二次项来自沟道电荷向漏端逐渐减少。只有当 VDS 远小于 VGT 时，才可进一步写成 ID ≈ βVGTVDS，像一个由栅压控制的电阻：

Ron ≈ 1/(βVGT)　（小 VDS 近似）

在这些条件下，加宽晶体管可以提高驱动能力，同时也增加电容，后面的动态分析要把两者一起计入。教材的 W、L 通常指有效电气尺寸，版图画出的 Wd、Ld 还需扣除工艺造成的尺寸差。

图 3.16：夹断发生在漏端，电流仍然流动

当 VDS 增大到 VGT，漏端的栅沟道电压刚好降至阈值，局部反型电荷趋近于零。继续提高漏压，会使靠漏端的沟道出现夹断（pinch-off）。图中的薄黑层在漏端之前结束，表达的是这个局部条件。

源端仍能向沟道提供电子，电子到达夹断区后受电场作用进入漏端。因此，夹断不意味着漏极电流消失。在理想长沟道模型中，沟道部分承担的电压近似停在 VGT，电流进入饱和：

ID,sat = βVGT²/2，　VDS ≥ VGT > 0

这里“饱和”描述电流对漏电压不再明显增加，仍可通过栅电压改变电流。把 VDS = VGT 代入上一节公式，两段得到相同电流，说明它们在边界处连续。

为什么实际饱和曲线还有斜率

漏压进一步上升，夹断区扩展，有效导电沟道变短，电流仍可能增加。教材用沟道长度调制系数 λ 作一阶修正：

ID ≈ I′D(1 + λVDS)

λ 的单位是 V−1，与第 2 章版图规则中的长度单位 λ 不是同一个量。该修正并没有包含所有短沟道效应；迁移率、速度饱和及阈值变化仍可能使平方律明显失准。

PMOS 可用 VSG、VSD、|VTp| 和正的电流幅值写对应关系。如果仍把“流入漏端”定义为正电流，PMOS 正常导通时的 ID 应带负号。先统一符号，再做两类管的比较。
