反偏电压在改变空间电荷

上一课的耗尽区里有固定的正、负离子。增加反偏电压，会使更多区域耗尽，空间电荷量也随之改变。外部电路必须提供与这种电荷变化对应的电流，所以反偏结仍然表现为电容。

对突变结，耗尽宽度随 √(φ₀ − VD) 增长。把耗尽区近似看成电介质，Cj = εSiA/Wj：反偏越大，Wj 越宽，结电容越小。

Cj(VD) = Cj0 / (1 − VD/φ₀)m

这里 Cj0 表示整个结在零偏置下的电容，单位是 F；若给出的是单位面积参数 cj0，需再乘面积 A。突变结常用 m = 1/2，线性渐变结常用 m = 1/3，具体数值取决于掺杂分布。

教材式 (3.4) 的 Qj 使用电荷量的正值大小，随 VD 增大而减小；随后式 (3.7) 把电容写成正的导数，符号约定不完整。若沿用电荷量大小，应写 Cj = |dQj/dVD|。本课始终取正电容，不把不同端口的电荷符号混在一起。

端点电容和一次跳变的等效电容不同

例 3.3 使用 cj0 = 2 fF/μm²、A = 0.5 μm²、φ₀ = 0.64 V。取 m = 1/2，在 VD = −2.5 V 时，单位面积电容约 0.903 fF/μm²，整个结约 0.451 fF。这是该偏置附近的小变化所见的电容。

如果端口从 −2.5 V 变到 0 V，电容沿途不断变化。用一个常数代表整次变化时，应保留总电荷变化：

Ceq = |ΔQ|/|ΔV| = [∫V₁V₂ Cj(V) dV] / (V₂ − V₁)，　V₂ > V₁

对上述区间，积分得到 Ceq/Cj0 ≈ 0.622，整个结的等效电容约 0.622 fF。它不是 −2.5 V 端点的 0.451 fF，也不严格等于两端电容的算术平均。后面估算门电路负载时，要先说明选择的是工作点电容还是电压区间内的等效电容。

图 3.8（PDF 72／书内 86）的纵轴写 Cj (fF)，图注却写 fF/μm²，单位不一致。本课只沿用其“反偏增大、电容减小”的趋势；上述数值按例 3.3 的参数独立复算。

图 3.10：电流、电荷和串联压降各有位置

沿上端进入模型，先经过 RS，再到电流源 ID 与电容 CD 的并联节点。电流源负责静态 I–V 关系，电容负责存储电荷；串联电阻来自中性区域等导电路径。

大电流时，RS 上的压降不可忽略。外部端口电压只有一部分落在内部结上，不能直接把外部电压代入理想结的指数式。图中的 VD 标在内部并联支路两端，正是在区分这两种电压。

模型的 CD 还可以包含正向偏置时少数载流子存储带来的电容。本章主要展开反偏耗尽电容，不能把两种存储机制都解释成耗尽区宽度变化。

模型边界先于仿真结果

温度改变热电压 φT，也改变 IS 等参数；只改指数分母不能完整预测温度影响。反向电压足够大时还可能发生击穿，理想反偏恒流近似失效；击穿后的损伤风险与电流及发热条件有关。

教材表 3.1 列出了二极管模型参数和默认值。有些电容参数默认是零，这只表示仿真输入没有提供该效应，不能据此说实际器件没有电容。

章节图中 01–02 → 07“源漏体结贡献电容” 的意义就在这里：MOS 的源漏结仍需使用二极管的电荷模型，所以这部分会继续用于后面的动态分析。
