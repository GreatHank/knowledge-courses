用最先到达的限制，合并几个电流区间

长沟道模型用 VGT 限制沟道电压，短沟道模型还要考虑速度饱和。§3.3.2 把它们整理成便于手算的式子。对 VDS ≥ 0、VGT > 0 的 NMOS：

Vmin = min(VGT, VDS, VDSAT)
ID = k′n(W/L)[VGTVmin − Vmin²/2](1 + λVDS)

漏压最小时，得到电阻区；过驱动最小时，得到普通夹断饱和；经验速度饱和电压最小时，则由速度限制电流。VGT ≤ 0 时，该手算模型把电流设为零，省略上一课的亚阈值漏电。

教材表 3.2 的参数由特定最小尺寸器件拟合而来。NMOS 的 VT0 = 0.43 V、VDSAT = 0.63 V、k′ = 115 μA/V²、λ = 0.06 V−1，不能脱离原书工艺与尺寸用于其他器件。PDF 92／书内 106 明确提醒，尺寸差异很大时需重新选参数。

图 3.26：等效电阻需要说明用于哪一段过程

左图把栅固定在 VDD，电容通过 NMOS 放电，漏压由 VDD 降到 VDD/2。右图的工作点从右向左移动。每一点的 VDS/ID 都可能不同，从原点指向工作点的连线体现这一比值；它不是曲线的局部斜率 dV/dI。

教材用这段过程的近似平均电阻替代非线性器件。若整个区间近似恒流且忽略 λ，取两个端点的 V/I 平均得到 Req ≈ 0.75VDD/Isat。其用途是简化延迟估计，不是宣称晶体管对所有状态都有同一个电阻。

式 (3.42) 写时间平均，式 (3.43) 又对电压均匀积分；两者一般不能直接等同，因为 dt 与 C dV/I 有关。本课将后者视为平均电阻的近似，未把它写成严格换元。

若目标是匹配延迟，可以从电荷守恒定义

下面是补充推导。取恒定负载电容 C、固定栅压，放电电流幅值为 ID(V)，由 I = C|dV/dt| 得到：

t50 = C∫VDD/2VDD dV/ID(V)，　Rdelay = t50/(C ln 2)

这样定义的 Rdelay 使一阶 RC 的半幅延迟与所选非线性放电过程相同。恒流时 Rdelay ≈ 0.721VDD/I，与前面的 0.75 接近但不相等。两种定义保留的量不同，不能不加说明就互换。

同模型条件下增大 W 会降低等效电阻，但也增加自身及前级所见的电容。判断是否更快，还要接上第 07 课；章节图中的电流线与负载线因此必须汇合。
