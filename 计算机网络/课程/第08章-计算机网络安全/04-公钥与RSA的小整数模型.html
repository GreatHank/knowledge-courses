公开锁与私人钥匙

公钥密码（public-key cryptography）用一对相关密钥。以保密通信为例，Alice用Bob公钥加密，Bob用自己的私钥解密。算法公开并不意味着私钥可由公钥轻易计算。Alice仍要确认收到的公钥确实属于Bob；否则Trudy可以用自己的钥匙替换它。

RSA把问题写成整数模运算。消息先编码成范围内的整数，实际协议还要加入安全编码；本课先只看数学骨架。

从两个素数生成一组参数

选不同素数p、q，计算n=pq和φ(n)=(p−1)(q−1)。选与φ(n)互素的e，再选d使ed≡1（mod φ(n)）。公钥包含(n,e)，私钥持有d等秘密信息。原书用z表示φ(n)。

0 ≤ m < n
加密：c = mᵉ mod n
解密：m = cᵈ mod n

教材取p=5、q=7，所以n=35、φ(n)=24。e=5与24互素，d=29满足5×29=145=1+6×24。m=12时c=17，再计算17²⁹ mod35得到12。应在乘方过程中不断取模，不必先构造巨大的完整幂。

遍历这35个消息代表

m = 12；c = 17；恢复 = 12

固定小整数参数；仅执行模幂，不生成真实密钥，不保护用户消息。

算得回来与安全是两个结论

按原书字母编码，love对应12、15、22、5，加密为17、15、22、10。15和22没有变化，这些固定点在小整数模型中很容易看见；相同明文也总有相同密文。能够还原不能证明保密。

标准补充：RFC 8017 §7.1、§8.1（2016）区分RSA原语与完整方案：RSAES-OAEP用于加密，RSASSA-PSS用于签名，各有编码规则。直接计算mᵉ mod n的裸RSA不是可部署的安全加密。教材PDF653的1024比特文字属于原书年代的讨论，本课程不把它转成当前选型建议。
