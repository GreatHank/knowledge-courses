沿一帧的形成和交付回看

发送端先根据路由结果确定当前下一跳；在本章的IPv4以太网情形下，ARP补出链路地址。链路层形成帧，用校验信息检查可能的比特错误，再按所在介质的接入规则发送。接收后的交换或三层转发决定后续处理范围。

要解释一个具体环境，先问它是否共享介质、是否全双工、属于哪个VLAN、下一跳是否跨路由器。脱离这些条件，单独背“以太网会碰撞”“MAC不会变”“每次都要ARP”都容易出错。

容易混淆的一对分别说明什么
差错检测 / 可靠交付检测发现不一致；可靠交付还需要相应恢复机制
发送时延 / 传播时延把位推出接口的时间 / 信号在介质中的行进时间
未知单播泛洪 / 广播帧多个出口复制的动作 / 目的地址类别
ARP缓存 / 交换机表IP→MAC / MAC及VLAN→端口
VLAN / IP子网二层转发范围 / 三层地址与路由范围
多路径总容量 / 单流速率多条流可共同使用的资源 / 某一流真正走到的路径与瓶颈

已经准备的演示能说明到哪里

CRC计算器展示模2编码与接收余数，包括一个可复算的漏检模式；ALOHA计算器展示固定N与p下的时隙概率；交换机步骤展示固定四帧的源地址学习和目的查询。它们帮助检查因果关系，不提供真实网卡、交换机、无线信道或网络负载的测量结论。

下一章将把链路放到无线环境中，重新考虑衰减、干扰、隐藏终端与移动性。此前CSMA/CD的条件不能直接搬到Wi-Fi；无线接入与互联网中的移动管理也不是同一个问题。
