14 倍，可以由两次移位得到

数学拆分位操作对应为什么成立
14x = 16x − 2x(x << 4) - (x << 1)左移 k 位对应乘 2 的 k 次方
14 × 3 = 48 − 600110000 - 00000110得到 00101010，即 42
unsigned mul14(unsigned x) {
    return (x << 4) - (x << 1);
}

这个版本把 x 明确设为 unsigned：左移和减法都按这个类型的模算术处理，与 14U*x 的结果一致。它展示编译器能利用的代数关系；实际代码通常直接写乘法，让编译器结合目标机器选择。

“能够改写”与“改写后一定更快”分开判断。指令代价、可并行程度和编译结果都会影响性能，本课没有测量性能，也不承诺移位一定优于乘法。

右移丢掉了余下的低位。算术右移对应向负无穷方向取整；C 的有符号除法从 C99 起向零取整。负数且不能整除时，这两个方向差 1。

负数先加偏置，把结果拉回向零的位置

除以 4 前，负数先加 3；再算术右移两位。一般的偏置是 2k−1。

/* 前提：本书平台对负的 int 使用算术右移 */
int div4(int x) {
    return (x < 0 ? x + 3 : x) >> 2;
}

?: 只选择一个分支：负数使用 x+3，非负数使用 x。这里固定除以 4，可以直接看清偏置，也避免把 1<<k 不加条件地套到任意 k。

负的有符号数右移在 C11 中由实现规定。这个函数用于解释教材的算术右移实现；可移植地表达除以 4，直接写 x / 4。补充：C11 委员会草案 N1570，§6.5.7。

把三个关键条件留在眼前

要检查什么有效范围或区别容易误读的地方
移位量 k0 ≤ k < 提升后左操作数的位宽不是看原来小变量的存储宽度
有符号左移左值非负，且乘 2 的 k 次方可表示负数左移，或越界，不能照搬模模型
算术与逻辑右移负数时填充的高位不同不能只盯着右边被丢掉的位

上述 C11 移位条件见 补充：C11 委员会草案 N1570，§6.5.7。图表中的固定宽度位模型与语言表达式分开使用。

先拓宽操作数，才能拓宽运算

/* 本书条件：int 为 32 位，long long 为 64 位 */
int x = 50000, y = 50000;
long long a = x * y;             // int 乘法先溢出：错误
long long b = (long long)x * y;  // 先提升乘法类型：2500000000
写法真正的乘法宽度赋值发生在何时
long long a = x*yx 与 y 都是 int，先做 int 乘法乘法求值之后；无法补救越界
long long b = (long long)x*y一个操作数先变宽，另一个随之转换宽类型运算完成之后

上面是两种写法的对照，不能把包含错误行的程序当作一个有确定输出的整体运行。正确行在所述宽度条件下能精确保存这个乘积。

回到 06 节点：整数部分连起来了——位宽与类型先决定规则，移位才可能成为乘除法的实现。下一课换一套编码：用有限位近似实数。
