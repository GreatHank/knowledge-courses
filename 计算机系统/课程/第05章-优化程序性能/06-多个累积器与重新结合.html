偶数位置和奇数位置，各自累积

对 [2, 3, 5, 7] 求积，偶数位置算 2×5=10，奇数位置算 3×7=21，最后合成 210。这两条链在最后合并之前，不需要彼此的累积值。

单独打开、放大或导出此图 · 依据教材机制绘制的伴读示意。

沿上行和下行分别看，两行内部仍然串行，但两行之间没有横向依赖。汇合节点要等两个结果都就绪。这是在一个线程中暴露指令级并行（ILP），不需要创建两个线程。

/* 根据 combine6 写成 double 乘法版本 */
double product_two_acc(const double *data, long n) {
    long i = 0;
    double acc0 = 1.0, acc1 = 1.0;
    for (; i < n - 1; i += 2) {
        acc0 *= data[i];
        acc1 *= data[i+1];
    }
    for (; i < n; i++)
        acc0 *= data[i];
    return acc0 * acc1;
}

输入需满足有效数组和非负长度条件，并允许改变浮点结合顺序。收尾元素归入 acc0，最后合并两部分；空数组仍返回 1。代码展示机制，未在本机编译或计时。

增加累积器，到哪一步就不再降低下界

设有 K 条均衡的独立累积链，每次运算延迟 L，运算吞吐量为 R 项/拍，每元素还需一次标量载入，载入能力为 M 项/拍。对足够长的循环，先忽略收尾与合并：

另一种办法：把不依赖 acc 的乘法提前算

原来的结合方式

acc = (acc * data[i]) * data[i+1];

两次乘法都在 acc 的跨轮依赖链上。

重新结合

acc = acc * (data[i] * data[i+1]);

元素之间的乘法可以先做；每两个元素只留下一次依赖 acc 的乘法。

运算总数没有因此减半，关键路径（critical path）上的运算数减少了。忽略边界开销，依赖给出的 CPE 下界可降为 L/2；仍须同时满足吞吐量等约束。教材浮点乘法的 combine5 为 5.01，combine6 与 combine7 都约为 2.51。

数值条件决定能否这样重排

数据与运算需要保留的条件
无符号整数加法／乘法固定宽度、相同无符号类型的模运算具有相应结合性质；注意整数提升与中间类型
有符号整数不能把 C 的未定义溢出当作回绕保证；需保证原式与改写式的相关中间运算均有定义
浮点加法／乘法重新分组可能改变舍入、上溢、下溢及特殊值行为；先明确误差或可复现性要求

例如按 IEEE 754 binary64、舍入到最近值计算：(1e16 + -1e16) + 1 得到 1，而 1e16 + (-1e16 + 1) 得到 0。后者在括号内先丢失了小量 1。这个例子用于说明数值机制，不表示某种分组永远更准确。

教材讨论补码算术的结合性时采用固定宽度的机器算术视角。写成 C 时仍需区分无符号模运算与有符号溢出的语言规则。对浮点程序，“结果差一点能不能接受”取决于任务，不能用速度收益代替判断。

这是教材 §5.10 与前面各表中的测量，不是所有机器上的固定阶梯。另一类并行是单指令多数据（single instruction, multiple data，SIMD）：一条向量指令同时处理多个数据通道。教材 AVX 例子用 256 位寄存器容纳 8 个 32 位值或 4 个 64 位值；它会改变“每条指令处理几个元素”的关系，因此也改变标量模型的吞吐下界。SIMD 的数据通道、多个累积器的独立依赖链，以及多线程的执行流，属于不同层次的并行。
