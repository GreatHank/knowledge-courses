取指和数据读写承担不同的访问任务，本章为它们提供可并行使用的接口，但访问的仍是同一个程序地址空间。图中画成两个块，不代表指令与数据一定存放在两份独立的物理存储中。

访存指令：ALU 算地址，内存才提供数据

# 假设 %rbx = 12，%rsp = 128
rmmovq %rsp, 100(%rbx)
步骤结果
读寄存器valA=128（要写的数据）；valB=12（基址）
加位移valE=12+100=112（写地址）
写内存M8[112] ← 128；%rsp 不因被当作普通源寄存器而改变
换成 mrmovq 100(%rbx), %rax仍算地址 112；valM=M8[112]，最后写 %rax

图中的 ALU → Data memory 连线传递地址；Data memory → Register file 连线传递读出的值。这里 112 是地址，128 是该地址处的数据，要分别跟踪。

栈指令：新地址和旧地址各有用处

操作pushq %raxpopq %rax
译码valA=旧 %rax；valB=旧 %rspvalA=valB=旧 %rsp
执行valE=旧 %rsp−8valE=旧 %rsp+8
访存M8[valE] ← valAvalM ← M8[valA]
写回%rsp ← valE%rsp ← valE；%rax ← valM

push 向新栈顶写入数据，pop 从旧栈顶读出数据。pop 需要同时更新栈指针（stack pointer）和目的寄存器，所以 SEQ 具有 E、M 两个写端口（write port）。

特殊情况 popq %rsp：两个写端口指向同一个程序寄存器，弹出值 valM 必须优先。最终 %rsp 等于弹出的字，而不是旧栈顶加 8。

下一条指令地址，为什么有三个候选？

指令必要的动作实际下一 PC
普通顺序指令按长度加到 valPvalP
jXX用 CC 和 ifun 求 CndCnd 真选 valC；否则 valP
call%rsp−8；将 valP 压栈valC，即目标地址
ret从旧栈顶读 valM；%rsp+8valM，即返回地址

call 保存的是它后面的地址，不是自身地址；Y86-64 call 长 9 字节，若位于 0x100，则保存 0x109。ret 不带目标常数，返回位置来自内存。
