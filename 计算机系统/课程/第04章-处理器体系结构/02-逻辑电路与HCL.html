一根选择线，怎样决定输出哪个值？

word Out = [
    s : A;
    1 : B;
];
sABOut
092121
19219

这里根据 s 的值二选一：s=1 时选 A，否则选 B。实现这种选择的硬件叫多路选择器（multiplexor，MUX）。后面会用它选择 ALU 输入、写入的寄存器，以及下一条指令的地址来源。

章节图位置：02 · 逻辑与状态 → SEQ。“提供构件”这条线表示 SEQ 用这些电路完成具体操作，硬件控制语言 HCL（hardware control language）则用来描述电路中的信号关系。

HCL 像 C，但这段代码没有软件执行顺序

组合逻辑

输出是当前输入的函数。输入改变，信号经过传播延迟（propagation delay）后改变输出；电路本身不记住上一次结果。

HCL 表达式

用名称描述信号关系。这里的等号不表示“执行一次赋值、写入变量”，表达式也不按 C 的短路过程执行。

case 表达式

逻辑上取第一个条件为真的结果。条件可以重叠，所以顺序代表优先级；最后的 1 是默认选择。

连接限制

本章组合逻辑（combinational logic）网络没有环，每个输入有明确驱动，不能把两个输出随意并接。跨时钟寄存器的反馈另当别论。

bool equal = (a && b) || (!a && !b);
bool needs_memory = icode in { IMRMOVQ, IRMMOVQ };

word chosen = [
    urgent : A;
    ready  : B;
    1      : C;
];

equal 比较两个单比特输入；in 是若干相等比较的简写。urgent 与 ready 同时为真时 chosen 选 A，但这不表示硬件先花一拍判断 urgent，再花一拍判断 ready。

有状态的电路：新输入到达，不等于旧输出立刻消失

时刻输入寄存器输出发生了什么
上升沿之前新值 y 已稳定旧值 x隔开前后两段组合逻辑
时钟上升沿采样 y更新为 y成为新的存储状态
上升沿之后可以继续变化保持 y 到下一次更新下一段电路读取这个已保存的值

看原图中间的时钟箭头：它标记状态更新的边界。后面每一级流水线寄存器都用这个边界，防止同一拍内的不同指令混在一起。

真实电路还要满足建立、保持和传播时间要求。本章用抽象延迟简化讨论，不能因此认为只要时钟沿到来，任意计算都能立即完成。

程序寄存器与硬件寄存器，是两种视角

信号含义例子
srcA / srcB要读的程序寄存器 IDsrcA=3 选择 %rbx
valA / valB从所选寄存器读出的值若 %rbx=21，则 valA=21
dstW / valW要写的 ID 与值指定写哪个寄存器、写多少
clock控制写入状态到上升沿才完成该次写入

程序员看到的 %rax、%rbx 是寄存器文件（register file）内可按 ID 选择的字；流水线中的 D、E、M、W 是保存一组字段的硬件寄存器。两者都保存位，但职责不同。

本章寄存器文件和数据内存的读操作按组合读取建模，写操作受时钟控制。整个寄存器文件仍是有状态器件，不能因为它的读取像组合逻辑，就说它没有存储。

ALU 的角色随指令改变

用途输入示例输出
subq %rdx,%rbxA=9，B=21，函数=减法B−A=12
计算访存地址A=位移 8，B=基址 0x10000x1008
压栈A=−8，B=旧 %rsp新栈顶地址
传送立即数A=立即数，B=0原立即数

算术逻辑单元（ALU）是组合逻辑块。本章减法按 B−A，要结合“源在前、目的在后”的汇编写法确认两个输入。ALU 能算出零、符号和溢出信息，但是否写入 CC 还由控制信号决定。
