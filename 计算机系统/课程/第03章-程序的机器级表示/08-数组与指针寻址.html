A[3]：编译器替你把“第几个”换成“多少字节”

int A[5] = {10, 20, 30, 40, 50};
int x = A[3];
元素A[0]A[1]A[2]A[3]A[4]
示例地址0x10000x10040x10080x100C0x1010
值1020304050
# A 的首地址在 %rdi，索引 i 在 %rsi
movl (%rdi,%rsi,4), %eax
# 对 A[3]：0x1000 + 3 × 4 = 0x100C，读出 40

元素地址 = 首地址 + 下标 × 元素字节数。这条 movl 读取 4 字节 int；地址计算使用 64 位寄存器。宽度和地址是两个维度，不能因为地址 64 位就读 8 字节元素。

下标、取地址与指针相减

C 表达式含义示例结果
A + 3 或 &A[3]产生指向第 3 个下标位置的指针0x100C；只计算位置
*(A + 3) 或 A[3]访问那个位置的 int 对象40
&A[3] - &A[1]同一数组内两个指针相减，按元素计数2，而不是 8
A + 5可以形成的一越尾指针可用于边界判断；不可解引用

p + 1 前进 sizeof(*p) 个字节。在 C 中，指针运算还受对象范围限制；不能把所有数值上可算的地址都当成合法指针。指针差的类型是 ptrdiff_t。

数组也不等于指针变量：本例 sizeof A 是 20；若 int *p = A，本书平台的 sizeof p 是 8。很多表达式里数组名会转换为首元素指针，这才使它们经常写起来相似。

二维数组是一行接一行，不是先存一排行指针

int A[5][3]元素数字节数／地址
一个 int14 字节
一行 A[i]312 字节
整个 A1560 字节
A[2][1]先跨 2 行，再跨 1 个元素xA + 2×12 + 1×4 = xA + 28

教材式 (3.1)：对 T D[R][C]，&D[i][j] = xD + sizeof(T) × (C×i+j)。列数 C 决定跨一行的距离；行数 R 决定整体共有多少行。

# A 在 %rdi，i 在 %rsi，j 在 %rdx；每行 3 个 int
leaq (%rsi,%rsi,2), %rax    # 3*i
leaq (%rdi,%rax,4), %rax    # 行起点 xA + 12*i
movl (%rax,%rdx,4), %eax    # 取 A[i][j]：再加 4*j

看起来都是 p[i][j]，内存可能完全不同

int A[2][3];       // 两行连续的 int 数组
int *rows[2];      // 两个 int*；每个需另指向有效行数据
对象第一层下标做什么取得 [i][j] 的主要访存
A按行大小算出 A[i] 的起点最终读取一次目标 int；中间不需要加载行指针
rows从指针数组读取 rows[i] 的地址值先读指针，再按 j×4 偏移读 int

在本书平台，A + 1 跨 12 字节，rows + 1 跨 8 字节。真正的二维数组不能直接当作 int** 使用；int** 会期待在内存中读到指针，而 A 开头存的是 int 数据。

固定列数、可变列数与地址递增

// C99 风格的可变长度数组参数；要求 n > 0 且下标有效
int get(long n, int A[n][n], long i, long j) {
    return A[i][j];
}
已知条件计算元素地址
列数固定为 3xA + 4×(3i+j)，常数乘法可改写为加法与缩放
列数运行时为 nxA + 4×(n×i+j)，需要把 n 纳入运行时计算
连续读一行可以维护当前指针，每次前进 4 字节
连续读一列每次前进整行跨度 4n 字节

同一遍历能写成下标，也能实现为指针递增；不必每轮重新做所有乘法。跨越多少字节既影响寻址，也将影响第 6 章的缓存局部性。

回到“08–09 · 对象布局”：数组按相同大小的元素定位；下一课的字段大小不同，要由编译器预先确定各自的偏移。
