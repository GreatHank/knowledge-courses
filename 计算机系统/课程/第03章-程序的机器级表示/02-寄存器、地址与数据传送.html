exchange：返回旧值，同时写入新值

初始条件（伴读设定）指令执行后的变化
%rdi = 0x1000；该处 long 值为 7movq (%rdi), %rax从地址 0x1000 读 8 字节，%rax = 7
%rsi = 42movq %rsi, (%rdi)把 42 写到地址 0x1000；%rdi 仍是 0x1000
%rax = 7ret调用者得到旧值 7；内存已变成 42

看第一条和第二条 mov 的方向：括号在源端就是读内存，在目标端就是写内存。指针的值和指针所指对象的值是两件事。前提是 xp 指向一个有效、可读写的 long 对象。

一个寄存器的几个名字，不是几个独立容器

%eax 是 %rax 的低 32 位；%ax 是低 16 位；%al 是低 8 位。写 32 位寄存器会清零高 32 位；写 8 或 16 位通常保留其余位。

改变一次写入宽度

每次都从 0x0011223344556677 开始，再向所选低位写入全 1。下表按高位到低位排列，不是内存地址顺序。

00112233445566FF

结果：0x00112233445566FF；其余 7 字节保持原样。

地址表达式先算地址，再决定是否读取

movq 8(%rdi,%rsi,8), %rax
# 有效地址 = 8 + R[%rdi] + R[%rsi] × 8

操作数形式表示的东西
$0x1000常量 0x1000
%rdi寄存器当前保存的值
(%rdi)寄存器给出的地址处的内容
8(%rdi,%rsi,8)地址为 8 + 基址 + 索引 × 8 的内存内容

看图中“有效地址 → movq 的结果”这条线：地址算完，还要到内存取内容。leaq 的另一条线停在地址数值本身，下一课专门展开。比例只能取 1、2、4、8，省略的位移和寄存器项按 0 处理。

复制多少位，补什么位，都要读出来

指令／规则输入示例结果含义
movq S,D8 字节复制；源和目标不能同时是普通内存操作数
movsbq %dl,%rax%dl = 0xAA符号扩展：0xFFFFFFFFFFFFFFAA，按补码解释为 −86
movzbq %dl,%rax%dl = 0xAA零扩展：0x00000000000000AA，值为 170
movslq %eax,%rax%eax = 0xFFFFFFFF32 → 64 位符号扩展，得到 −1 的 64 位表示
movl %edi,%eax32 位源复制低 32 位，同时清零 %rax 高 32 位；不需要 movzlq
# 内存到内存的普通复制，用寄存器中转
movq (%rdi), %rax
movq %rax, (%rsi)

后缀先确认宽度，再确认扩展方式。“写得更窄”“零扩展”“符号扩展”是不同动作；联系第 2 章的位宽变化一起看。

push 与 pop：数据移动，还会更新栈指针

操作先做什么再做什么
pushq %rax%rsp 减 8把 %rax 写到新的栈顶
popq %rdx从旧栈顶读取 8 字节到 %rdx%rsp 加 8

原图里的地址向上增加，所以栈向低地址增长时画面向下延伸。pop 并不擦除旧字节，它改变栈的当前边界。这里先认识操作，第 6 课再解释函数为什么需要它。
